# SPHEREx Sky Atlas & Science Results Viewer

## Overview

The SPHEREx Sky Atlas is an interactive web application designed to visualize and explore astronomical observations and scientific analysis results from the **SPHEREx mission**.

The interface integrates sky-coordinate navigation, astronomical source catalogs, time-grouped observations, photometric analysis, and candidate identification into a single platform.

The primary goal is to make processed SPHEREx data more accessible and intuitive, allowing users to investigate changes in astronomical sources across different wavelengths and observing epochs.

The interface works alongside a separate Python scientific analysis pipeline responsible for downloading, calibrating, processing, and analyzing the observations.

## 1. Main Features

### 1.1 Interactive Sky Atlas

The Sky Atlas allows users to explore the celestial sphere using equatorial coordinates.

Features include:

- Navigation using Right Ascension (RA) and Declination (Dec)
- Interactive sky panning and zooming
- Adjustable Field of View (FOV): **0.2°–180°**
- Built-in astronomical target presets
- Astronomical source searching
- Display of reference coordinates and selected objects

The sky display also incorporates astronomical catalog information, including **HYG** and **Gaia DR3**.

Catalog availability and density may vary depending on the selected sky region and data coverage.

### 1.2 Science Results Explorer

The Science Results section provides access to previously processed SPHEREx observations.

Users can select:

1. An astronomical target
2. A detector bandpass or bandpass combination
3. An analysis run
4. A scientific visualization product

The currently published dataset contains five targets:

| Target | Description |
|---|---|
| WISE 0855 | Nearby, extremely cool brown dwarf |
| Barnard's Star | Nearby star with high proper motion |
| Epsilon Indi B | Nearby brown-dwarf companion system |
| RW Aurigae | Young variable stellar system |
| R Draconis | Variable star |

Each target supports nine published bandpass analysis configurations.

| Type | Bandpass |
|---|---|
| Individual | D1, D2, D3, D4, D5, D6 |
| Combined | D1 + D2 + D3 |
| Combined | D4 + D5 + D6 |
| Full range | D1 + D2 + D3 + D4 + D5 + D6 |

**Total: 5 targets × 9 configurations = 45 analysis runs.**

These results are generated by the Python scientific analysis pipeline and published as structured data and image products for the website.

## 2. Scientific Visualization Modes

The Science Results Explorer provides four primary visualization modes.

### 2.1 GIF / Group

Displays time-grouped observations and their corresponding image sequences.

- View the sequence of original group images.
- Inspect individual observing periods.
- Compare image structures and detected sources across epochs.
- Use available MJD information to understand the observation timeline.

Time grouping and stacking are performed by the Python analysis pipeline before publication.

### 2.2 STACK

Displays the original STACK overview figure produced during scientific processing.

The STACK visualization helps users inspect higher-SNR image products and the results of the source-detection workflow.

### 2.3 SED — Spectral Energy Distribution

Displays the spectral energy distribution of a selected astronomical source.

The default visualization is **Epoch-to-epoch evolution**, allowing users to compare spectral behavior across observing periods.

An alternative time-group-based view is also available.

These plots are derived from the photometric analysis performed on individual original SPHEREx observations using ePSF fitting.

### 2.4 Time Grouping Diagnostic

Displays the diagnostic figure generated by the time-grouping procedure.

This helps users understand the temporal organization of observations used to generate the scientific results.

## 3. SPHEREx Observation Viewer

The Observation Viewer provides a larger interface for inspecting the published observation animations.

The Viewer is designed to remain visible alongside the interactive sky atlas, allowing the user to examine both the astronomical target's reference location and the corresponding scientific images.

### 3.1 Animation Controls

| Control | Function |
|---|---|
| Prev | Display the preceding image in the observation sequence |
| Blink / Pause | Automatically play or pause the image sequence |
| Next | Display the following image |
| Show annotated GIF | Toggle between annotated and original image sequences |
| Brightness | Adjust visual display brightness |

The Viewer uses frames extracted from the actual published GIF animations.

**Both annotated and original image sequences are retained.**

When switching annotation modes, the Viewer preserves the corresponding epoch position so that users can compare images directly.

### 3.2 Annotated vs. Original GIF

The annotated GIFs are based on the original observation sequences, with additional source markers produced by the scientific analysis algorithms.

The checkbox **Show annotated GIF** controls whether those annotations are displayed.

- **Enabled:** Show annotated observations.
- **Disabled:** Show the original unannotated observations.

The animations do not represent separately measured photometric datasets; they are alternative visual presentations of the corresponding observation sequence.

The source annotations should be interpreted as **algorithm-generated candidates**, rather than independently verified astronomical classifications.

### 3.3 Brightness Adjustment

The Viewer brightness setting defaults to **1×**.

Brightness adjustments affect only the displayed image. They do not modify:

- Original FITS observations
- Photometric measurements
- Detected-source catalogs
- Spectral Energy Distributions

### 3.4 Astronomy Education Panel

The Viewer includes a supplementary astronomy reading section.

One of two educational topics is selected when the Viewer opens:

**Variable Stars**

Explains the distinction between intrinsic and extrinsic stellar variability, including pulsating, eruptive, cataclysmic, X-ray, eclipsing-binary, and rotational variability.

**Fast-Moving Objects**

Introduces high-speed stellar motion and high proper motion, using S4714 and Barnard's Star as astronomical examples.

Users can select **Another topic** to switch the displayed article.

## 4. Language and User Guide

The interface supports:

- **English (EN)** — default language
- **Traditional Chinese (ZH)** — selectable alternative

The website also provides an interactive **HOW TO USE** guide covering target selection, data visualization, Viewer controls, and sky navigation.

## 5. How to Use

### Step 1 — Select a Target

Open the Science Results section and choose one of the five available astronomical targets.

### Step 2 — Select a Bandpass

Choose an individual bandpass or one of the supported combined-band configurations.

### Step 3 — Choose an Analysis Run

Select the available analysis run.

Each run has its own source catalog and associated scientific outputs.

**Source IDs are local to each run and should not be assumed to represent the same object across different runs.**

### Step 4 — Explore Scientific Results

Switch among:

- GIF / Group
- STACK
- SED
- Time Grouping

Select an individual source when source-specific SED results are available.

### Step 5 — Open the Viewer

Select **Open Viewer** to examine the image sequence alongside the sky atlas.

Use Prev, Blink, and Next to navigate the observing epochs. Toggle Show annotated GIF to compare the original and annotated versions.

### Step 6 — Explore the Sky

Use RA/Dec inputs, preset targets, search, panning, or zooming to navigate the corresponding region of the sky.

## 6. Project Architecture

The website is implemented using **HTML, CSS, and JavaScript**, with the scientific datasets provided through precomputed static files.

The main components are:

| Component | Description |
|---|---|
| `index.html` | Main sky atlas, interface structure, and language controls |
| `science-run-browser.js` | Target, bandpass, run, source, and science-product navigation |
| `science-run-browser.css` | Science Results styling |
| `spherex-viewer.js` | Observation Viewer and animation controls |
| `spherex-viewer.css` | Viewer layout and styling |
| `sky-map-tools.js` | Sky search and navigation utilities |
| `allsky-stars.js` | All-sky stellar catalog visualization |
| `user-guide.js` | Interactive user guide |
| `science-runs/` | Published science products and analysis-run manifests |
| `catalogs/` | Astronomical catalog data |

### Scientific Data Organization

The published scientific results are organized by astronomical target and analysis run.

```text
science-runs/
├── index.json
├── wise-0855/
├── barnards-star/
├── epsilon-indi-b/
├── rw-aurigae/
└── r-draconis/
    └── <analysis-run>/
        ├── manifest.json
        └── media/
            ├── group_stacks_marked.gif
            ├── group_stacks_plain.gif
            ├── group_stacks_sources_epsf.png
            ├── time_grouping_diagnostic.png
            ├── viewer_marked_frames/
            └── viewer_plain_frames/
```

Individual run manifests provide references to source catalogs, original Group images, SED plots, animated images, and other scientific products.

This design allows users to explore multiple targets and bandpass configurations without rebuilding the analysis in their browsers.

## 7. Running the Website Locally

The frontend does not require a JavaScript build process.

Start a local HTTP server from the project directory:

```bash
python3 -m http.server 8765
```

Then open:

```text
http://localhost:8765/
```

A local HTTP server is recommended because browsers may restrict access to JSON and other local files when the website is opened directly using the `file://` protocol.

## 8. Scientific Data and Backend Integration

The Python notebooks and the web interface serve different purposes.

**Python scientific pipeline**

- Processes downloaded SPHEREx observations
- Performs image alignment and time grouping
- Generates higher-SNR stacked images
- Detects and matches astronomical sources
- Performs ePSF photometry
- Constructs Spectral Energy Distributions
- Identifies moving-source and variable-source candidates
- Exports scientific results

**Web interface**

- Loads published analysis manifests
- Displays astronomical images and animations
- Provides interactive scientific visualization
- Supports sky-coordinate navigation
- Allows comparison of annotated and original observations
- Presents SED and time-grouping results

The current website is a **static visualization frontend**. It does not perform arbitrary-coordinate SPHEREx data retrieval, FITS calibration, or photometric fitting directly in the browser.

## 9. Scientific Considerations

Users should be aware of the following limitations:

- Candidate moving and variable sources require further scientific verification.
- Data availability can vary by sky region, bandpass, and observation time.
- Source identification numbers are specific to individual analysis runs.
- Time grouping and photometric results depend on the selected processing configuration.
- The plotted sky position is a reference coordinate and does not by itself establish a scientific detection.
- Display operations such as brightness adjustment do not alter the underlying scientific measurements.

## 10. Project Goal

The long-term goal is to provide an accessible interface that connects astronomical coordinates with multi-epoch, multi-wavelength scientific analysis.

By integrating the SPHEREx processing pipeline with an interactive sky atlas, the project aims to help users explore potential moving and variable astronomical objects through both visual observation and quantitative scientific results.

The website serves as the presentation and exploration layer of this broader astronomical analysis system.
